클립 추가 방법

data/clips.json 파일을 열어 아래 형식으로 항목을 추가하면 사이트에 자동으로 반영돼요.

1) 유튜브 영상으로 추가하기

{
  "id": "unique-id-1",
  "title": "클립 제목",
  "category": "offense",
  "type": "pick-and-roll",
  "tags": ["픽앤롤", "하이볼"],
  "team": "우리팀",
  "notes": "여기에 메모를 적어요",
  "source": "youtube",
  "youtubeId": "영상URL의 v= 뒤 11자리",
  "start": 95,
  "end": 118,
  "dateAdded": "2026-09-21"
}
  • youtubeId: 유튜브 주소 youtube.com/watch?v=VIDEOID 에서 VIDEOID 부분.
  • start / end: 클립 구간을 초(second) 단위로 입력. 예: 1분 35초는 95.
  • category: offense(공격) 또는 defense(수비).
  • type: 세부 전술 유형을 영문 key로. 자유롭게 새 유형을 만들어도 되고, 필터 목록에 자동으로 나타나요.

2) 직접 촬영한 영상으로 추가하기

videos/ 폴더에 mp4 파일을 넣고 아래처럼 작성하세요.

{
  "id": "unique-id-2",
  "title": "클립 제목",
  "category": "defense",
  "type": "zone-defense",
  "tags": ["2-3존"],
  "team": "",
  "notes": "메모",
  "source": "local",
  "file": "my-clip.mp4",
  "start": 0,
  "end": 20,
  "dateAdded": "2026-09-21"
}

⚠️ GitHub은 큰 파일 업로드에 제한이 있어요. 가능하면 미리 필요한 구간만 짧게 잘라서(수 MB 수준) 올리는 걸 추천해요.

3) 저장 후 반영

파일을 저장하고 커밋/푸시하면 사이트에 반영돼요. 로컬에서 미리보려면 basketball 폴더에서 간단한 로컬 서버(예: python3 -m http.server)를 켜고 브라우저로 열어보세요.
