    전술 짜면서 드는 생각, 고민 등을 자유롭게 적어두는 공간이에요. 자동 저장돼요.

      사용 방법

      폴더로 정리하기

      맨 처음 화면에서 공격 / 수비를 고르면, 그 안에서 화면 아래 + 새 폴더 버튼(전술 추가 버튼 옆에 작게 있어요)으로 원하는 폴더를 만들 수 있어요. 폴더 안에 또 폴더를 만들 수도 있어요(예: 지역 상대 → 2-3존). 폴더 카드의 ✎ 아이콘으로 이름을 바꿀 수 있어요.

      메모장

      상단 메모장 버튼을 누르면 여러 개의 메모를 따로따로 적을 수 있어요. + 새 메모로 새 메모를 추가하고, 왼쪽 목록에서 이전에 쓴 메모들을 클릭해서 다시 볼 수 있어요.

      영상 추가하기 / 수정하기

      오른쪽 아래 + 새 전술 / 영상 추가 버튼으로 유튜브 링크와 이름만 적으면 바로 추가돼요. 재생 화면에서 제목 옆 ✎로 전술 이름/구분/폴더를 수정하고, 번호 옆 ✎로 지금 보고 있는 영상의 링크·구간·이름을 수정할 수 있어요.

      클립 구간(시작/끝) 지정하기

      영상 전체가 아니라 원하는 구간만 재생되게 하려면 시작 시간과 종료 시간을 적어주세요. 1:35처럼 분:초로 적거나 95처럼 초 단위 숫자로 적어도 돼요.

      순서 바꾸기 / 접기·펼치기

      오른쪽 Tactic Map 패널의 화살표를 누르면 펼치고 접을 수 있고, 드래그로 같은 단계끼리 순서를 바꿀 수 있어요.

      삭제하기

      전술/폴더의 × 버튼을 누르면 비밀번호를 물어봐요 (폴더는 안이 완전히 비어있어야 삭제 가능).

      ⚠️ 브라우저에만 저장돼요

      여기서 추가/수정/삭제/정렬한 내용은 지금 이 브라우저에만 저장돼요 (localStorage). 모두에게 영구 반영하려면 상단의 내보내기 버튼으로 최신 상태를 받아서 저장소의 basketball/data/plays.json을 교체하고 커밋/푸시하세요.
