    사용 방법

    폴더로 정리하기

    맨 처음 화면에서 공격 / 수비를 고르면, 그 안에서 + 새 폴더로 "지역 상대", "맨투맨 상대"처럼 원하는 폴더를 만들 수 있어요. 폴더를 열면 그 안의 전술만 모아서 볼 수 있어요. 폴더를 지정하지 않고 전술을 추가하면 미분류 폴더에 들어가요.

    영상 추가하기

    오른쪽 아래 + 새 전술 / 영상 추가 버튼을 누르고 유튜브 링크와 이름만 입력하면 바로 추가돼요. 이미 있는 전술(예: Horns)에 다른 예시 영상을 더 넣고 싶으면, 카드나 재생 화면의 + 이 전술에 예시 영상 추가 버튼을 쓰세요. 번호 버튼(1, 2, 3...)을 누르면 그 예시 영상이 재생돼요.

    클립 구간(시작/끝) 지정하기

    영상 전체가 아니라 원하는 구간만 재생되게 하려면 시작 시간과 종료 시간을 적어주세요. 1:35처럼 분:초로 적거나 95처럼 초 단위 숫자로 적어도 돼요. 비워두면 시작은 영상 처음부터(또는 링크에 있는 시간), 끝은 영상이 끝날 때까지 재생돼요.

    순서 바꾸기 / 삭제하기

    오른쪽 패널에서 드래그해서 폴더나 전술의 순서를 바꿀 수 있어요. 각 항목의 × 버튼으로 삭제할 수 있어요 (폴더는 안이 비어있어야 삭제할 수 있어요).

    ⚠️ 브라우저에만 저장돼요

    여기서 추가/삭제/정렬한 내용은 지금 이 브라우저에만 저장돼요 (localStorage). 다른 기기나 다른 사람에게는 보이지 않아요. 모두에게 영구 반영하려면 상단의 내보내기 버튼으로 최신 상태를 plays.json 파일로 받아서, 저장소의 basketball/data/plays.json 파일을 그걸로 교체하고 커밋/푸시하세요.
